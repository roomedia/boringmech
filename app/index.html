Relayer API 키—

정산된 포지션을 자동으로 현금으로 바꾸는 데 필요합니다. 키가 없으면 상환만 보류되고 매매는 계속됩니다. 키는 polymarket.com → 설정 → API Keys → Relayer API Keys에서 만들고, 생성 시 표시되는 API Key와 Signer Address를 그대로 입력하세요. Signer Address는 연동된 지갑 주소와 같아야 합니다.
